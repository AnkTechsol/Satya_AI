## 2024-05-24 - Cross-Site Scripting (XSS) in Streamlit Dashboard Alerts\n**Vulnerability:** Pulse data alerts and Goal Guardian alerts dynamically injected unsanitized user-provided input (like agent names, goal strings, and alert messages) directly into the Streamlit dashboard using st.markdown(..., unsafe_allow_html=True).\n**Learning:** Even internal or agent-generated strings must be treated as untrusted input if they are ever injected into unsafe HTML contexts. Streamlit's unsafe_allow_html flag bypasses default protections, requiring explicit manual sanitization (e.g., html.escape).\n**Prevention:** Audit all instances of unsafe_allow_html=True across the codebase and enforce a strict policy to apply html.escape() to any dynamically interpolated variable before rendering.
